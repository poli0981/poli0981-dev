## Platform binaries (not in the table above)

npm installs only the prebuilt binary matching the build machine, so these vary by platform
and are surveyed in prose rather than generated.

**`@img/sharp-*` — Apache-2.0 AND LGPL-3.0-or-later.** sharp's prebuilt binaries bundle
libvips, part of which is LGPL. This is fine here and worth writing down rather than
rediscovering: sharp is a **build-time** dependency (`imageService: "compile"`), the binary
runs on the build machine and is never served to a visitor, and LGPL obligations attach to
_distributing_ the library. The built site contains only the resulting AVIF/WebP files.

**`@resvg/resvg-js-*`, `lightningcss-*` — MPL-2.0.** File-level copyleft, used unmodified as
build tools, likewise never shipped.
